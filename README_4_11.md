# Báo cáo tiến độ đợt 1

- Khởi tạo Express + TypeScript và Prisma + PostgreSQL.
- Thiết kế schema User, Category, Product, InventoryMovement, Invoice, InvoiceItem và AuditLog.
- Thiết lập Docker Compose cho PostgreSQL.
- Xây dựng JWT, HttpOnly Cookie, middleware role và error handler.
- Tạo seed dữ liệu mẫu cho môi trường local.
